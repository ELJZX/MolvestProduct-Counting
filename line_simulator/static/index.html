Приращение за клик

Клик по карточке выбранной линии насчитывает продукцию текущего продукта линии. Если выбранный продукт отличается от текущего на линии — насчёт не выполнится («Код продукции не соответствует»): симулятор сам код продукта не меняет. Смена кода продукта — только по кнопке «Изменить код» на карточке линии с вводом пин-кода.
Выберите хотя бы одну линию слева.
