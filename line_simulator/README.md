# Эмулятор линии (сервис тестирования)

Отдельный сервис для MolvestCountingSystem: открывается окно браузера, в котором
перечислены все линии; выбираете код продукции и кликом мыши «насчитываете»
продукцию. Данные отправляются на сервер Django через **тот же API, что
использует контроллер ОВЕН** (`POST /api/v1/counter/`), поэтому задания,
минутные ряды, диаграммы, отчёты и простои работают как с настоящим
контроллером. В будущем этот сервис заменит реальный контроллер ОВЕН —
протокол обмена останется прежним.

## Запуск

1. Убедитесь, что сервер Django запущен (http://127.0.0.1:8000).
2. Из этой папки (line_simulator):

   ```bash
   python server.py
   ```

   или двойным кликом по `run.bat`.

3. Откройте **http://127.0.0.1:8050**.

## Настройка

По умолчанию сервис обращается к Django на http://127.0.0.1:8000 с ключом
`super-secret-controller-key` (как в `.env` проекта). При необходимости
задайте переменные окружения:

```bash
set DJANGO_BASE_URL=http://127.0.0.1:8000
set CONTROLLER_API_KEY=super-secret-controller-key
python server.py --port 8050
```

## Как пользоваться

- Вверху выберите продукт (поиск по названию, коду 001–999 или коду 1С).
- Задайте приращение за клик (1/5/10/100 или своё значение).
- Клик по карточке линии (или кнопке «Насчитать») отправляет показание:
  счётчик линии увеличивается, диаграммы и отчёты в системе обновляются.
- **Эмулятор сам код продукта не меняет.** Насчитать можно только тот
  продукт, который уже установлен на линии; если выбранный продукт отличается
  от текущего — выводится уведомление **«Код продукции не соответствует»**,
  показание не отправляется.
- **Смена кода продукта** — только по кнопке **«Изменить код»** на карточке
  линии: открывается диалог с вводом **пин-кода** (по умолчанию `2020`,
  настраивается в админке Django, «Настройки системы»), затем — подтверждение
  «Вы точно хотите изменить код продукта…». При неверном пин-коде —
  «Операция отклонена», при отмене — «Операция отменена пользователем».
  Смена выполняется через отдельный endpoint `POST /api/v1/sim/switch/`.
